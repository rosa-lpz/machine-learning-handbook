# Linear Regression

A regression analysis is a method for modeling relationships between variables. It makes it possible to infer or predict a variable. Regression predicts a number among potentially infinitely possible numbers.

The variable we want to infer or predict is called the dependent variable or criterion.

The variables we use for prediction are called independent variables or predictors.

## Main ideas
1. use least-squares to fit a line to the data

2. Calculate R²

3. Calculate a p-value for R²
